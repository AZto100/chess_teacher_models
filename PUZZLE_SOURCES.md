# Puzzle sources and validation

Source collection: https://github.com/fsmosca/games (GPL-3.0). The repository credits The Week in Chess and Chess.com. Each puzzle contains its specific PGN source URL, event, round, players, year, and zero-based startPly. tournamentLine contains only moves from the recorded mainline, never an invented game continuation.

The collection covers 2021–2022 tournament records, including the Olympiad and open tournaments. This is a selected corpus, not an exhaustive archive of every tournament.
